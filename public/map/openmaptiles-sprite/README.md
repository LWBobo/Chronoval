# OpenMapTiles basic style sprites

Vendored from https://openmaptiles.github.io/maptiler-basic-gl-style/
for ChronoFrame MapLibre styles (`app/assets/mapStyles/chronoframe_*.json`).

Only used when map provider is `maplibre`. Offline map basemap still
requires either Protomaps + local PMTiles, or a reachable tile endpoint.
